# DR1 PC source integration lesson

The new path is an ordinary LunaHook full UTF-16 input stream, with an exact executable/resource gate and default-off private flag. It does not turn an input pointer or a FreeType cache event into a draw role. A company-named Chunsoft hook targets a different game, and the Danganronpa PSP scripts do not cover the PC executable

The real PC dispatcher table operand relocates with ASLR. Static disk bytes and runtime signature comparisons must account for that operand; the original complete-string helper's relative call bytes remain stable

Every text callback clears TextBuffer before any rejection, including disabled control and a failed pointer/context check. Reuse cannot leak a previous sentence

Source withdrawal needs both fresh callback refusal and a final Reader receipt guard. Clearing a revoked source must check its origin so it cannot erase a newer unrelated Luna line. A new opaque grant cannot reuse the same process after withdrawal; restart is required for this minimal adapter

Root integration and exact evidence are in docs/engine-danganronpa-runtime.md. Append these facts to the historical ENGINE-ADAPTATION-NOTES during root consolidation rather than creating a truncated replacement for that ignored file
