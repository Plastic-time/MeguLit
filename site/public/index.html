读的时候，什么都在游戏里

阅读层浮在游戏上面，不抢焦点，点它也不会让剧情往下走

译文直接写进游戏的文本框

内嵌替换把游戏自己的台词原地换成你要的样子：日文加注音，或者日文加译文。用游戏自己的字体和版面画出来，眼睛不用在两个窗口之间来回跳

汉化补丁就是译文，一句不等

装过汉化补丁的游戏，MeguLit 直接拿补丁里的译文对上日文原文，台词一出来译文就在。KiriKiri、BGI、Siglus、YU-RIS、Artemis、Ren'Py 都已实测；补丁里没有的句子会提前机翻好

注音先听游戏的

游戏自带 ruby 的地方，用游戏标的读音；没有标的，再按词典和上下文判断。人名、当て字也跟着作品走

点一下查词，拖一段查短语

离线词典，查过的词自动进单词本。也可以选中整句，让 AI 讲语法和语境。翻译支持 DeepL、Google、Gemini、DeepSeek、Sakura、Ollama 等，密钥加密存在本地

读过的，都能留下来

查过的词、读过的句子和花掉的时间，MeguLit 都替你记着

查过的词、读音、释义和掌握程度，还有它出现在哪部作品、哪一句里

在阅读层点「制卡」，卡片带上游戏截图和原声，没配音的旁白用本地语音补上。复习直接用 Anki 的卡片和调度，评分写回 Anki

阅读字数、时长、查词次数、阅读日历，每部作品读了多少，按年、月、周、日切换

读过的每一句原文和译文都按会话存好，回头找哪句话一搜就有

少折腾

换回日文原版

MeguLit 读的是日文台词，所以剧情得是日文。Steam 中文 / 英文版可以一键换回日文；手上有日文原版的话，压缩包、文件夹、光盘镜像都能直接选，MeguLit 自动对照替换

  • 支持 .iso、.bin / .cue 光盘镜像，只有 InstallShield 安装程序的老光盘也能直接解包
  • 替换前全部备份，一键还原
  • 启动的是中文版时，会直接告诉你怎么换成日文

自动更新

每次启动检查一次新版本，后台下载、校验完再问你要不要重启更新。只替换程序文件，游戏库、学习记录和设置都留着

        五步开始读

        1. 下载并解压

          下载 MeguLit-v1.2.8-win-x64.zip，解压到任意文件夹，运行 MeguLit.exe

        2. 选完整版或精简版

          完整版约 565 MB，一次装齐注音词典和语音引擎（推荐）；精简版约 107 MB，其余组件以后在设置里补装

        3. 选游戏文件夹

          MeguLit 扫描文件夹和 Steam，自动找出日文原版 EXE，系列作品归到一起

        4. 启动游戏，用窗口模式玩

          点作品 →「启动游戏」，阅读层自动接上，按 Alt + T 呼出菜单

        5. 零基础先学五十音

          学习 → 五十音：25 课、五十音图和三个假名小游戏，例句来自你自己玩过的游戏

        常见问题

        全屏玩的时候翻译显示不全，或者文字跑到了桌面上

        请把游戏切到窗口模式。独占全屏下游戏会盖住其他所有窗口，阅读层没法稳定地画在游戏上面。窗口拉大一点也没关系

        读到的是乱码，或者根本不是日文

        剧情必须是日文原文。汉化版先试试「工具 → 日文原版恢复」；如果只是文本流选错了，在阅读层里一键重选

        下载很慢，或者打不开 GitHub

        本页的下载按钮默认走 megulit.com 自己的镜像，和 GitHub Releases 自动同步。镜像不可用时，「备用下载」里还有两个 GitHub 加速镜像和 GitHub 直连

        更新会不会弄丢我的数据

        不会。自动更新只替换程序文件，data、logs、cache、runtime、models 都不碰，旧的 MeguLit.exe 还会留一份 MeguLit.rollback-update.exe

        点「启动游戏」提示「无法检查游戏是否已运行」

        v1.1.0 已经修复。旧版本在部分电脑上（多半是杀毒软件拦了进程查询）会这样，更新就好

        Anki 连不上

        先打开 Anki，并装好 AnkiConnect（MeguLit 里可以一键安装）。端口 8765 被别的程序占用也会连不上

        某个游戏读不到文字

        不同引擎差别很大。请在 GitHub Issues 留下游戏名，最好附上 MeguLit 的 logs 文件夹

        要钱吗？会收集我的数据吗？

        免费，源码以 GPL-3.0 公开。学习记录和设置都存在你自己的电脑上；翻译接口的密钥加密保存在本地，只发给你选的那家服务
