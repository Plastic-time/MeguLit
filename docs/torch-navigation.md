# 传火碑页面与操作

传火碑属于左侧主导航，使用 `torch` 路由、页面历史和现有星芒选中指示器。场景挂载在 `#main`，不是模态弹层。页面切换在动态资源准备过程中也能撤销，离开立即释放场景和 WebGL 上下文

滚轮向前靠近，向后退远，使用帧时间阻尼延续运动；系统减少动态效果时缩放目标立即生效。按住左键或触屏拖动，远景调整视角、靠近后平移查看碑面。沿用暖白金色的 `grab` / `grabbing` 光标，点击碑面不再突然跳近。双击或键盘 `0` 复位，`+` / `-` 缩放；翻页继续用原页码箭头、方向键和 PageUp / PageDown

实现复用现有相机与 RAF，不同时挂第二个 OrbitControls。交互参考 [Three.js OrbitControls](https://threejs.org/docs/pages/OrbitControls.html) 的滚轮 dolly、拖动与阻尼合同，没有复制其代码或增加依赖。场景、火焰、姓名数据、#0 和匿名传火人命名保持原合同

首开先显示准备状态，同时加载字体、GSAP、烘焙资源和首批名单。确认清单哈希后，35 张纹理与 3 个体积文件并行读取。同画质重进复用最近一档的 CPU 侧资源，场景、GPU 纹理和 WebGL 上下文随路由释放。离页同时取消本页的着色器就绪轮询

亲验时从游戏库开传火碑，看星芒是否跟随、底部是否无关闭按钮。轻滚一下松手，看镜头继续收敛；按住拖动，核对光标和视角。分别在准备中和场景出现后直接切到首页或游戏库，再重进传火碑

开发者工具 Performance 面板的 `torch:*` 用户计时可对比冷开与同画质重进。分别记录 `modules`、`font`、`gsap`、`bake-assets`、`first-page`、`build-scene`（资源校验失败时为 `build-scene-fallback`）、`shader-ready` 和 `first-frame`。这些区间有重叠；`first-frame` 从页面模块挂载开始计时，入口模块加载另记在 `modules`。早期候选的真实 Edge 鼠标及 WebGL 退出回放见交接；这次的启动和取消流程由 Node 夹具回放，最终画质、手感和实机耗时待亲验
